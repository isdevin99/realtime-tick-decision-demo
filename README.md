# 量化实时数据 · 逐笔成交明细

**逐笔成交看得清，大单方向有依据。**

本项目以「量化实时数据，逐笔成交明细」为主题，介绍如何整理逐笔成交信息，并基于成交方向和金额，观察主动买卖力量及大单动向。适用于行情研究、数据核对与盘中复盘。

## 项目示例

仓库内提供一个独立、离线可运行的 Python 最小示例，演示如何将规范化的逐笔成交记录转换成透明、可解释的观察结果：

1. 读取每行一条 JSON 的逐笔成交。
2. 校验股票代码、交易时间、成交价、股数、成交额和方向。
3. 按每只股票的 5 秒区间，分别汇总主动买入额与主动卖出额。
4. 计算买卖净额，并根据用户设置的阈值标记买方力量、卖方力量或无明显信号。
5. 对每条结果给出对应的计算理由，方便复核判断过程。

示例数据均为合成数据。示例程序**不连接行情服务器、不包含实时行情授权、不发送订单**；它仅演示逐笔数据的基本处理和一种简化观察规则。实际可用字段、数据权限和接入方式以服务提供方及所购产品为准。

## 运行

需要 Python 3.10 或更新版本。核心示例只使用 Python 标准库；运行测试需要 `pytest`。无需安装行情 SDK 或连接上游。

```bash
python -m tickdemo examples/synthetic_ticks.jsonl --threshold-yuan 20000
```

每个输出事件为一行 JSON，例如：

```json
{"ts_code":"000001.SZ","bucket_start":"09:30:00.000","bucket_end":"09:30:04.999","buy_yuan":"60000","sell_yuan":"25025","net_yuan":"34975","tick_count":2,"status":"observe_buy_pressure","reason":"buy-sell net 34975 >= threshold 20000 yuan"}
```

执行测试：

```bash
python -m pytest -q
```

## 输入字段

输入为 UTF-8 JSONL，每行是一条已经解码且归一化的成交记录：

| 字段 | 类型 | 含义 |
|---|---|---|
| `ts_code` | string | 证券代码，例如 `000001.SZ` |
| `time` | string | 交易所时间，`HH:MM:SS.mmm` |
| `price` | decimal/string | 元/股 |
| `volume` | integer | 股 |
| `turnover` | decimal/string | 元 |
| `bs_flag` | string | `B` 主动买，`S` 主动卖，`C` 撤单，`N` 中性或方向不明 |

## 处理规则与边界

- 缺少成交量、成交额或方向时，示例拒绝该记录，不会根据价格变化推断或虚构方向。
- `C` 撤单与 `N` 中性/方向不明成交不会计入买卖净额。
- 新的 5 秒区间到来时，程序关闭前一区间；文件结束时显式处理最后一个区间。
- 无成交的时间段不会被补成零成交，也不会当作断流证据。
- “大单动向”在本示例中只是阈值化的主动买卖成交额净值观察，不等同于真实资金身份识别，也不保证预测效果。
- 生产接入时应依照数据提供方正式授权的接口说明，并先确认账户实际收到所需字段；不要把行情快照误当成逐笔成交。
- 股票代码和样例行情均为合成/通用格式。本仓库不包含真实客户数据、认证信息或内部平台代码。
